# BukaKios WebView Simple

WebView-only project. No DB, no Redis — API-only.

---

## Quick Start

**Development:**

```bash
sudo docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

**Live / Production:**

```bash
sudo docker compose up -d --build
```
